
# AI Usage Disclosure

AI assistance was used during development to help structure the implementation, draft Python functions, prepare evaluation cases, and write documentation.

## Human Responsibilities
- Inspecting the supplied policy documents.
- Reviewing effective dates and precedence.
- Running the implementation and evaluation.
- Checking outputs and identifying limitations.

## Implementation
The current prototype uses deterministic Python logic. It does not call an AI model at runtime.

## Verification
AI-generated suggestions and policy interpretations must be checked against the original source documents. Passing evaluation tests does not independently prove that every policy answer is correct.
